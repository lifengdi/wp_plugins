## WordPress插件
一些自己开发、使用的WordPress插件。

- comment-user-agent: 显示评论者的UA信息
- daily-zaobao: 每日早报自动发布，定时抓取每日早报/知乎日报/微博热搜榜/网易新闻头条/今日热榜并整合为一篇文章
- comment-user-rank: 显示评论者的等级
- history-today: 历史上的今天，显示历史上的今天的部分名人或者历史大事
- post-heatmap: 仿照github热力图做的文章热力图
- wp-dylan-custom-plugin: 一些自定义插件合集
- wp-native-link-enhance: 原生链接增强插件
